## 📖 Glosario

| Sigla / Placeholder | Significado |
|---------------------|-------------|
| `<N>` | Número incremental que identifica el número del Trabajo Práctico. Ej: `01`, `02`, etc. |
| `<M>` | Número incremental que identifica la versión de un mismo ítem de configuración dentro de un Trabajo Práctico. Ej: `01`, `02`, etc. |
| `<Nombre_Presentacion>` | Nombre de la presentación/filmina teórica. |
| `<Nombre_Tema>` | Nombre o título del tema correspondiente. |
| `<Nombre_Material>` | Nombre o título del libro/paper de bibliografía. |
| `<Nombre_Autor>` | Nombre del autor del libro correspondiente. |
| `<Especificacion>` | Especificación/tema al que está dirigido el template. |
| `<Extension>` | Extensión del archivo; puede variar de formato. Ej: `.doc`, `.jpg`, `.jpeg`, `.xlsx`, `.css`, `.html`, `.js`, etc. |
| `<TipoResolucion>` | Tipo de resolución de la actividad. Valores posibles: `ResolucionPropia`, `ResolucionDeClase` o `ResolucionGrupal`. |
| `ISW` | Ingeniería y Calidad de Software. |
| `TP` | Trabajo Práctico. |
| `TED` | Tecnología, Entretenimiento y Diseño. |
| `PRE` | Presentación. |

## 🏷️ Criterio de línea base

Como grupo definimos que la **línea base** se establece luego de la entrega de cada trabajo práctico evaluable, en cada instancia y, si corresponde, luego de su correspondiente corrección.

Cada línea base se marca mediante un **tag de Git** en el repositorio y utiliza la nomenclatura **`v[MAJOR].[MINOR]`**, donde:

- **`MAJOR`** → se incrementa con cada trabajo práctico evaluable entregado. El valor `1` corresponde al estado inicial del repositorio (antes de cualquier entrega evaluable).
- **`MINOR`** → se incrementa con correcciones o ajustes menores realizados sobre una versión ya estable.
